How it works

Three steps

  1. Copy the prompt

    Paste the install prompt into your agent. No slash command is needed.

  2. Ask for the work

    Build, restyle, critique, or audit. Only the references that task needs are loaded.

  3. Verify the result

    Run npm run verify in the skill folder to check links, tokens, contrast, accessibility, and code.

FAQ

Questions before you install

Does it need a website, dashboard, or server?

No. It works inside your agent and project. This page is a front door, not a setup step.

Is this official Apple guidance?

No. It is Apple inspired, not Apple branded, and it is not affiliated with or endorsed by Apple Inc.

Which platforms are covered?

iOS, Android, web, macOS, Windows, Linux, watchOS, visionOS, Flutter, React Native, Compose, SwiftUI, Tauri, and Electron.

How does it keep context small?

SKILL.md routes each task to the smallest useful reference set. It does not load the whole corpus unless you ask for a full build or full audit.

Can it review existing work?

Yes. Five lens review and an optional scored review use hard caps, evidence labels, and path and line findings.

What does verification check?

Links, static patterns, tokens, contrast, accessibility, code hygiene, and motion. Rendered axe and visual diff checks are opt in.

Where is a finished example?

The Lumen demo in the skill repository is a complete flagship page built with the skill alone.

What can I reuse?

Original material and code are MIT licensed. The vendored research snapshot is documented in THIRD_PARTY.md. No Apple owned media is bundled.
