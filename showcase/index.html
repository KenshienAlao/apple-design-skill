FAQ

Questions before you install

Needs a website?

No. It runs inside your agent and project.

Official Apple guidance?

No. Apple-inspired, not Apple-branded or affiliated.

Which platforms are covered?

iOS, Android, web, desktop, watchOS, visionOS, and cross-platform stacks.

Keeps context small?

SKILL.md loads only what the task needs.

Reviews existing work?

Yes. Five-lens and scored review return path and line findings.

Verification checks?

Links, tokens, contrast, accessibility, and code. Rendered checks are opt in.

Finished example?

The Lumen demo in the repo is built with the skill.

What can I reuse?

MIT. Vendor notes are in THIRD_PARTY.md. No Apple media.
